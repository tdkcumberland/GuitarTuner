# GuitarTuner

A lightweight, offline guitar tuner for Windows built with C++ and JUCE.

## Features

- Real-time pitch detection using the YIN algorithm
- Analog-style arc needle with smooth 60Hz refresh
- Detects all six standard guitar strings (E2 A2 D3 G3 B3 E4)
- Visual feedback — needle turns green when in tune (±5 cents)
- Six string buttons mirroring guitar orientation (low to high, left to right)
- Custom tuning presets — create, edit, and delete your own tunings
- Presets persist to disk between sessions
- Standard tuning protected from deletion
- Silence gating — needle holds on note decay, clears on silence
- No internet connection required, no telemetry, no ads
